# Hint Generation Prompt

Generate a progressive hint for a coding challenge.

## Hint Levels
1. **Subtle**: Point in the right direction, name the concept
2. **Moderate**: Explain the approach, show pseudocode structure
3. **Direct**: Show solution approach with explanation

## Input
- Challenge description
- User's current progress
- Specific question (if any)
- Hint level requested

## Output
- Hint content appropriate for the level
- Whether next level is available
